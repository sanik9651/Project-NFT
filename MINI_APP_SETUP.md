# 🦦 Настройка Mini App для Rich Preview

## Шаг 1: Создай Mini App в BotFather

1. Открой [@BotFather](https://t.me/BotFather)
2. Отправь команду `/newapp`
3. Выбери своего бота
4. **Short name:** `nfttransfer` (латиницей, без пробелов)
5. **Title:** `NFT Transfer`
6. **Description:** `Перевод Telegram NFT одной кнопкой`
7. **Photo:** Загрузи картинку 640x360 (можешь использовать любую NFT GIF как картинку)
8. **GIF:** Загрузи анимированную GIF (Telegram NFT анимация)
9. **Web App URL:** `https://project-nft-app.vercel.app`

## Шаг 2: После создания получишь ссылку вида:

```
https://t.me/ИМЯ_БОТА/nfttransfer
```

Эта ссылка будет показывать **большой preview с GIF** в чате!
